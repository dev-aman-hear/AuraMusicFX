# Aura Music

A modern glassmorphism music player built with JavaFX.

## Features

* 🎵 MP3, WAV and M4A playback
* 🎨 Dynamic album artwork
* 📝 Synchronized lyrics (.lrc support)
* 📂 Automatic folder restore
* ⏯ Playback position restore
* 🔀 Shuffle mode
* 🔁 Repeat modes
* 📋 Queue management
* ⌨ Keyboard shortcuts
* 🪟 Modern transparent UI
